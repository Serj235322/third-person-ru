# Третье лицо

Локальное приложение для Windows, которое помогает преобразовать русскоязычный текст одного рассказчика из первого лица в третье лицо. Исходник вставляется из буфера обмена; результат можно проверить, исправить, скопировать или сохранить в TXT.

**Текущая версия: 1.2.0.** [Скачать готовую программу из Releases](https://github.com/Serj235322/third-person-ru/releases).

- `ThirdPerson-Setup-1.2.0.exe` — один офлайн-установщик для Windows 10/11. Предлагает установку .NET Framework, если его нет, создаёт ярлыки и добавляет удаление через настройки Windows. Нужны права администратора.
- `ThirdPerson-Windows-v1.2.0.zip` — переносная версия. Распакуйте архив и откройте `ThirdPerson.exe`; Framework должен быть уже установлен.

## Возможности

- Полностью локальная обработка: без нейросетей, серверов, учётных записей и сетевых запросов.
- Обычное окно Windows; отдельная видеокарта, Python и Word для запуска не нужны.
- До 5 000 000 символов за проход, обработка в фоновом потоке с отменой.
- Замена местоимений, предлогов и словарных форм глаголов.
- Ограниченные правила контекста для омонимов: «мой», «мою», «еду», «плачу» и других.
- Защита оформленных цитат и реплик, проверка несовпадения рода рассказчика.
- Список замечаний с выбором варианта, подтверждением исходного слова и отменой последнего решения.

```text
Я живу в Москве. Мой телефон остался дома. Я плачу за аренду.
↓
Он живёт в Москве. Его телефон остался дома. Он платит за аренду.
```

## Запуск и ограничения

Нужен .NET Framework 4.8 или новее. Офлайн-установщик предназначен для Windows 10 (1607+) и Windows 11; Windows 7 не входит в его целевые системы. Сборка приложения x86. Цель — слабые ПК с 2 ГБ ОЗУ, однако отдельные испытания на физическом компьютере с 2 ГБ пока не проводились.

Программа использует конечный набор правил и словарь OpenCorpora. Она не выполняет полноценный смысловой и синтаксический анализ. Обрабатывайте одного рассказчика за раз и вычитывайте результат, особенно отрицания, принадлежность вещей, участников событий и редкие смыслы слов. Отсутствие замечаний не означает отсутствие ошибок.

Подробности: [инструкция](docs/USER_GUIDE.md), [проверки версии 1.2](docs/VALIDATION-1.2.txt), [история изменений](CHANGELOG.md).

## Сборка

Из корня репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Скрипт использует системный компилятор .NET Framework и создаёт `ThirdPerson.exe` в корне. NuGet и интернет для сборки не нужны. Словари `Verbs.tsv` и `Agreement.tsv` встраиваются в EXE. Для запуска не требуется держать их отдельными файлами, однако сведения об их лицензии необходимо сохранять при распространении.

Самопроверка обработчика:

```powershell
$report = Join-Path (Get-Location) 'engine-test.txt'
$test = Start-Process .\ThirdPerson.exe -ArgumentList '--self-test', ('"{0}"' -f $report) -Wait -PassThru
Get-Content $report
if ($test.ExitCode -ne 0) { throw 'Проверка не прошла' }
```

Для оконных проверок используется `--ui-test <путь-к-отчёту>`. Они открывают собственное тестовое окно с вымышленным текстом. `src/prepare_dictionary.py` и `src/prepare_agreement.py` нужны только разработчику для повторного создания словарей; их зависимости указаны в скриптах.

Сборка установщика и сценарии проверки описаны в [installer/README.md](installer/README.md). В корне можно запустить `Build-Installer.ps1`: он проверит официальную зависимость Microsoft и соберёт единый EXE в `dist`.
