# Цифровая подпись программы

На 5 октября 2026 года приложение и установщик версии 1.2.1 **не подписаны сертификатом издателя**. Вложенный официальный пакет .NET Framework имеет действительную подпись Microsoft; эта подпись не распространяется на наше приложение и установщик.

Для распространения EXE через GitHub нужна Authenticode-подпись доверенным сертификатом Code Signing. Сертификат или сервис подписи требует проверки личности/организации издателя. Самостоятельно созданный сертификат не делает приложение доверенным для посторонних компьютеров.

Подпись подтверждает издателя и целостность файла. Она не гарантирует немедленное исчезновение предупреждений SmartScreen: новым файлам и издателю нужна репутация. Предупреждение UAC о повышении прав остаётся, поскольку установщик запрашивает права администратора.

Варианты:

- SignPath Foundation предоставляет бесплатную подпись подходящим открытым проектам после рассмотрения заявки. Нужны соответствие условиям, доступный исходный код, проверяемая сборка и защищённые учётные записи. MIT проекта позволяет рассмотреть этот путь, но не гарантирует одобрение. Подпись программы Foundation использует издателя SignPath Foundation.
- Доверенный сертификат Code Signing от удостоверяющего центра — платный путь с проверкой издателя и защищённым хранением ключа.
- Azure Artifact Signing — сервис Microsoft с проверкой личности и ограничениями доступных стран/типов заявителей; сначала нужно проверить возможность регистрации конкретного издателя.
- Публикация MSIX через Microsoft Store предоставляет подпись Microsoft после сертификации. Это отдельный канал распространения; загрузка EXE с GitHub не получает подпись Store автоматически.

После получения доступа к подписи нужно подписать `ThirdPerson.exe`, затем собрать установщик из подписанного EXE и подписать также установщик и его деинсталлятор. При использовании Inno Setup следует настроить SignTool и SignedUninstaller. Для подписи необходима доверенная временная метка; ключи и учётные данные не размещаются в репозитории. Проверка подписи и вычисление контрольных сумм выполняются после подписи, перед публикацией.

Обычным пользователям доступ к сервису подписи не нужен. Работа приложения остаётся локальной; подпись выполняется разработчиком при подготовке релиза.
