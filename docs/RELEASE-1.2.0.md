Локальное преобразование русского текста для Windows.

**Установка одним файлом:** скачайте `ThirdPerson-Setup-1.2.0.exe` (118,45 МиБ), запустите с правами администратора и пройдите русский мастер. Установщик проверит .NET Framework 4.8 или новее; при отсутствии предложит установку встроенного официального пакета Microsoft. Загрузка компонентов из интернета не нужна. Создаются ярлыки на рабочем столе и в меню «Пуск», доступно удаление через настройки Windows. Если потребуется перезагрузка, мастер предложит её в конце. Целевые системы установщика — Windows 10 (1607+) и Windows 11, x86/x64; Windows 7 не входит в эту сборку.

**Переносная версия:** `ThirdPerson-Windows-v1.2.0.zip`. Распакуйте и запустите `ThirdPerson.exe`; .NET Framework 4.8+ должен быть установлен заранее.

В приложении есть правила ближайшего контекста для омонимов, выбор варианта в замечаниях, подтверждение исходного слова и отмена последнего решения. До 5 000 000 символов за проход. Обработка локальная, отдельная видеокарта не нужна. Правила ограничены: вычитывайте результат перед использованием.

Проверки установщика: 196 успешных проверок в изолированной папке; установленное приложение прошло 1210 проверок движка. Реальная установка Microsoft .NET на чистой Windows, Windows 10/x86 и физический ПК с 2 ГБ ОЗУ пока не проверены. Подробности — в `ThirdPerson-Setup-1.2.0-validation.txt`. Сам установщик пока без цифровой подписи издателя; Windows может показать предупреждение. Подпись Microsoft у встроенного пакета проверена.
