# Третье лицо — версия 1.2.1

Приложение для Windows: преобразует русский текст одного рассказчика из первого лица в третье лицо. Исходник вставляется из буфера обмена; результат можно исправить, скопировать или сохранить в TXT. Доступны установщик и переносной архив.

Приложение использует грамматические правила и встроенный словарь OpenCorpora. Нейросетей, серверов, сетевых запросов, учётных записей и фоновых служб нет. Python, Word, браузер и отдельная видеокарта для запуска не нужны.

## Запуск

**Установщик (Windows 10/11).** Запустите `ThirdPerson-Setup-1.2.1.exe`, разрешите запуск с правами администратора и пройдите русский мастер. Он проверит .NET Framework 4.8 или новее. При отсутствии компонента разрешите его установку и примите условия в официальном мастере Microsoft. Пакет включён в EXE, загрузка из интернета не нужна. Выберите папку и оставьте включённым ярлык на рабочем столе. Если потребуется перезагрузка, мастер предложит её в конце; после перезагрузки откройте приложение через ярлык. Удаление доступно в настройках Windows и меню «Пуск». Framework при удалении приложения остаётся.

**Переносной архив:**

1. Распакуйте архив в удобную папку.
2. Запустите `ThirdPerson.exe` двойным щелчком. Установка и права администратора не требуются.
3. Нужен установленный .NET Framework 4.8 или новее. Программа собрана как x86 и предназначена для 32- и 64-разрядной Windows 10/11. На компьютере с физическими 2 ГБ ОЗУ отдельная проверка ещё не проводилась.

Оба словаря и значок встроены в EXE. Рядом с `ThirdPerson.exe` должен оставаться `ThirdPerson.exe.config`: это настройки чёткого отображения при масштабировании экрана. При передаче программы сохраняйте файл `THIRD-PARTY.txt` с указанием источника и лицензии словаря.

## Как пользоваться

1. Обрабатывайте показания одного человека за один проход. Документы с несколькими рассказчиками разделяйте на фрагменты.
2. Вставьте текст слева кнопкой «Вставить» либо Ctrl+V / Shift+Insert. Кнопка заменяет весь исходник; сочетание клавиш вставляет текст в выделенную позицию.
3. Выберите «Он» или «Она» в соответствии с полом рассказчика. Программа меняет лицо, а не пол: «Я приехала» → «Она приехала».
4. Нажмите «Преобразовать». Во время обработки поля защищены от редактирования, доступна отмена.
5. Просмотрите вкладки «Замены» и «Проверить». Выбор строки выделяет соответствующее место в исходнике и результате. Для замечаний с вариантами выберите нужную форму под списком и нажмите «Применить»; если исходная форма верна, нажмите «Оставить как есть».
6. Вычитайте результат и при необходимости исправьте его справа. Скопируйте готовый текст в нужный документ либо сохраните в TXT (UTF-8).

Кнопка «Пример» загружает вымышленные учебные фразы в мужском или женском роде в соответствии с текущим выбором рассказчика. Если выбрать другой пол после загрузки примера, уже введённый текст не переписывается автоматически: загрузите пример заново или получите предупреждения о несовпадении. Она запрашивает подтверждение перед заменой уже введённого текста.

## Что преобразуется

- Местоимения: «я» → «он / она», «меня» → «его / её», «у меня» → «у него / у неё», «мне» → «ему / ей».
- Сочетания с предлогами: «со мной» → «с ним / с ней», «ко мне» → «к нему / к ней», «обо мне» → «о нём / о ней».
- Однозначные формы настоящего и будущего времени из локального словаря: «живу» → «живёт», «приобщаю» → «приобщает», «могу» → «может».
- Прошедшее время остаётся прежним: «Я приехал» → «Он приехал». Возвратные «себя», «свой», «свою» также сохраняются.

Словарь содержит более 65 тысяч записей форм первого лица с вариантами третьего лица. Неоднозначные разборы сохраняются для проверки, если не подошло отдельное правило контекста. Это число включает множественное число и варианты написания е/ё, а не количество разных глаголов.

## Меньше ручных замечаний — новое в версии 1.2

Для ряда омонимов добавлены ограниченные правила ближайшего контекста. Они включены автоматически:

- «Мой телефон остался дома» → «Его / Её телефон остался дома»; «Я продал мою квартиру» → «Он продал его квартиру»; «в моём доме» → «в его доме».
- «Я мою руки» → «Он моет руки». «Мы моем руки» → «Они моют руки» только при включённой опции группы.
- «Я купил еду», «Я вижу еду в холодильнике»: слово «еду» распознаётся как существительное и сохраняется без отдельного замечания. «Я еду в Москву» → «Он едет в Москву».
- «Я плачу за аренду» → «Он платит за аренду»; «Я плачу навзрыд» → «Он плачет навзрыд». Отрицание сохраняется: «Я не плачу налоги» → «Он не платит налоги».
- «Несколько дам» сохраняется как существительное; «Я дам показания» → «Он даст показания». «Я узнаю завтра» → «Он узнает завтра», «Я обычно узнаю голос» → «Он обычно узнаёт голос».
- Распространённые словарные омонимы после явного «я / я не»: «Я иду», «Я веду допрос», «Я ношу очки», «Я варю суп».

В учебном примере при правильном выборе пола число замечаний сократилось с четырёх до одного: остаётся «Мы с Петровым», где нужно определить группу. При неверном выборе пола три замечания о роде сохраняются дополнительно.

Контекстные замены включаются во вкладку «Замены» с пояснением правила в пределах лимита списка. Распознавания существительных без изменения слова учитываются в счётчике «Разобрано по контексту». Полного синтаксического или смыслового анализа нет: используются короткие локальные шаблоны, наборы предлогов и распространённых слов. Необычный порядок слов, пропуски пунктуации, редкие смыслы и сложные предложения могут привести к ошибочному выбору. Исходник остаётся доступным для сравнения.

## Исправления из списка

Для неразрешённых омонимов и словарных форм доступны варианты. Например, для «плачу» можно выбрать «платит» или «плачет»; при нескольких вариантах ни один не выбран заранее. Кнопка «Применить» меняет только выделенное слово, снимает его замечание и переходит к следующему. Позиции остальных замечаний и замен пересчитываются, поэтому проверку можно продолжать без нового преобразования.

«Оставить как есть» означает, что проверяющий подтвердил исходную форму. Текст не меняется, замечание снимается. Для некоторых замечаний, включая несовпадение рода, автоматических вариантов нет: сначала проверьте настройки и исходник. Не подтверждайте ошибочную форму только ради очистки списка.

«Отменить решение» возвращает последнее решение по списку, включая подтверждение исходной формы. Это отмена одного последнего шага. После следующего решения отменяется уже оно. Применённые изменения добавляются во вкладку «Замены» в пределах её лимита. Отдельного файла журнала и автоматического сохранения нет.

Свободное редактирование результата, изменение исходника или настроек отключает кнопки решений, относящихся к прежней обработке. Новое преобразование строит результат из исходника заново и после подтверждения заменяет ручные правки.

## Цитаты и группы

Опция «Сохранять цитаты и реплики» включена по умолчанию. Содержимое парных кавычек «…», "…", “…” и „…” не преобразуется; поддерживаются вложенные цитаты и несколько строк. Строки с начальным тире сохраняются и получают замечание. Некоторые похожие на прямую речь фрагменты после двоеточия также сохраняются до конца строки. При незакрытой открывающей кавычке остаток текста сохраняется и помечается для проверки.

Если весь исходник заключён в кавычки, он может целиком остаться без изменения. Уберите внешние кавычки, если это только оформление вставленного показания. Отключение защиты разрешает преобразование и внутри цитат, поэтому используйте эту опцию осознанно. Защита не распознаёт все способы оформления прямой речи, в частности все варианты речи без кавычек и одинарные ASCII-кавычки.

«Мы», «нас», «наш» и глаголы первого лица множественного числа по умолчанию сохраняются с замечаниями. Когда состав группы определён и её допустимо обозначить как «они», включите «Мы → они». Например, «Мы живём» → «Они живут».

## Проверка рода — новое в версии 1.1

При обнаружении несовпадения рода программа показывает предупреждение над текстом и помещает эти замечания первыми во вкладке «Проверить», даже если раньше было много менее важных замечаний.

Например, исходник «Я купил еду» и выбор «Она» дают замечание на слове «купил». Форма сохраняется: программа не решает сама, неверно выбран пол или ошибочно написан исходник. Проверьте выбор «Он / Она»; при необходимости исправьте исходник или результат вручную. Смена настройки после обработки требует нового преобразования.

Проверка использует отдельный встроенный словарь прошедшего времени, кратких прилагательных и причастий: «был / была», «мог / могла», «готов / готова», «должен / должна». Она выполняется в ограниченном контексте с явно указанным «я», допускает распространённые частицы и наречия и некоторые однородные сказуемые. Пунктуация и другие промежуточные слова прекращают этот контекст. При пропущенном «я», сложных вставках, нескольких субъектах и длинных предложениях несовпадение может остаться неотмеченным. Полноценного синтаксического анализа нет.

Формы других участников, вещей и защищённых цитат не проверяются по полу рассказчика в этом локальном контексте: «Петров был», «мой телефон остался», «Петров сказал: „Я купил…“» не являются ошибкой женского рассказчика. Грамматический род названия профессии также не переписывается автоматически.

## Ручная проверка обязательна

Программа помогает подготовить текст, но не выполняет полноценный синтаксический и смысловой анализ. Она не устанавливает, к какому участнику относится «он», «его» или «её», не выбирает ФИО и не переводит произвольную прямую речь в косвенную. При нескольких действующих лицах замените неясные местоимения именами вручную.

Омонимы, для которых не подошли правила ближайшего контекста, сохраняются с замечаниями: отдельное «плачу» не определяет оплату или плач, а «мой телефон» без сказуемого может оказаться просьбой помыть телефон. Словарные неоднозначности и некоторые неизвестные формы тоже отмечаются. Поскольку часть фразы может быть преобразована, до выбора варианта возможно «Он плачу» или «Он [неизвестный глагол первого лица]».

Список «Проверить» не гарантирует обнаружения всех непреобразованных форм и ошибок. Перед использованием результата необходимо вычитать весь текст, включая отрицания, предположения, принадлежность вещей и участников действий. Оформление Word не переносится; абзацы сохраняются, стандартный Windows-редактор нормализует переводы строк.

После свободного изменения результата позиции списка перестают быть точными: переход к ним отключается, замечания остаются для справки. При исправлении кнопками под списком позиции сохраняют точность. После изменения исходника предыдущий результат автоматически не обновляется.

## Большие тексты и память

Лимит исходника — 5 000 000 символов за проход. Обрабатывается весь текст последовательно; поиск отдельных релевантных фрагментов не используется. При превышении лимита вставка кнопкой и поддерживаемыми сочетаниями клавиш отклоняется с сообщением — текст нужно разделить. В поле результата допускается расширение текста до 10 000 000 символов.

Для экономии памяти в каждой вкладке показаны до 2 000 записей. Во вкладке «Проверить» замечания о роде имеют приоритет перед остальными. Общие счётчики учитывают все замены и замечания. Этот предел касается только списка; текст обрабатывается полностью. Для удобной проверки документов с большим количеством замечаний обрабатывайте меньшие фрагменты.

Цель — слабые ПК с 2 ГБ ОЗУ и встроенной графикой. Измерения на проверочном компьютере приведены в `VALIDATION.txt`; они не являются замером на ПК с 2 ГБ ОЗУ. Скорость зависит от процессора, версии Windows и свободной памяти. Вставка и отображение миллионов символов занимают больше времени, чем сами словарные замены.

Текст не сохраняется автоматически, истории документов и автозагрузки при запуске нет. Кнопка сохранения пишет только выбранный пользователем TXT-файл. После закрытия несохранённые правки теряются. Копирование помещает текст в системный буфер обмена; его история и синхронизация управляются средствами Windows.

## Исходный код и сборка

В папке `src` находится код C#; `Verbs.tsv` — подготовленный словарь глаголов, `Agreement.tsv` — метаданные грамматического рода. Файлы `.meta.json` содержат их происхождение и статистику. `Build.ps1` собирает EXE системным компилятором .NET Framework, без NuGet и сетевых запросов. Из папки программы можно выполнить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Самопроверка обработчика: `ThirdPerson.exe --self-test <полный-путь-к-отчёту.txt>`. Проверка оконной части: `ThirdPerson.exe --ui-test <полный-путь-к-отчёту.txt>`. Они работают с вымышленными встроенными данными, включая большой текст, и записывают технический отчёт в указанный файл. В обычном режиме приложение этих отчётов не создаёт.

Скрипты `src/prepare_dictionary.py` и `src/prepare_agreement.py` нужны только для повторной подготовки словарей разработчиком. Зависимости и версии указаны внутри скрипта; на компьютеры пользователей их устанавливать не нужно. Происхождение и условия распространения словаря описаны в `THIRD-PARTY.txt`.
