# Офлайн-установщик

`ThirdPerson-Setup-1.2.1.exe` — один файл для Windows 10 (1607+) и Windows 11, x86/x64. Windows 7 не входит в целевые системы этой сборки. Сценарии ниже проверены на Windows 11; Windows 10 пока не проверена на отдельной машине.

Мастер работает на русском языке, запрашивает права администратора, предлагает папку установки и создание ярлыка на общем рабочем столе (по умолчанию включено). В меню «Пуск» появляются приложение и удаление. По умолчанию файлы устанавливаются в `Program Files (x86)\ThirdPerson` на 64-разрядной системе.

Проверяется ключ .NET Framework `v4\Full\Release` в 32- и 64-разрядных представлениях реестра. Значение не меньше `528040` означает Framework 4.8 или новее; уже установленная 4.8.1 также подходит. Другие .NET Runtime и SDK эту проверку не заменяют.

При отсутствии Framework мастер предлагает установить официальный встроенный пакет Microsoft. Открывается оригинальный мастер Microsoft с его лицензионными условиями. Отказ, отмена или ошибка блокируют установку приложения. Успех дополнительно подтверждается проверкой реестра. Коды `3010` и `1641` означают успех с перезагрузкой: приложение устанавливается, автозапуск подавляется, в конце предлагается перезагрузка. Сохраните открытые документы перед перезагрузкой. Если Microsoft требует сначала устранить проблему Windows, выполните его указания и запустите установщик повторно.

Пакет .NET включён без изменений, поэтому установщик весит около 120 МБ. Интернет для загрузки компонентов при установке не нужен. Программа и словари занимают около 8 МБ после установки; временно потребуется место для распаковки .NET и место для его системных файлов. Языковой пакет .NET не нужен для русского интерфейса приложения.

Удаление через настройки Windows удаляет файлы программы и созданные установщиком ярлыки. Framework остаётся системным компонентом. Сохранённые пользователем TXT не перечислены в составе установки и не удаляются. Повторная установка использует выбранную ранее папку. Перед обновлением сохраните результат и закройте приложение; принудительное закрытие не применяется.

## Сборка

Нужны Windows, .NET Framework с компилятором C# и [Inno Setup](https://jrsoftware.org/isdl.php) (проверена 6.7.3). В корне репозитория:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build-Installer.ps1
```

При первой сборке скрипт скачивает официальный пакет Microsoft и проверяет закреплённую SHA-256 и цифровую подпись Microsoft. Повторная сборка использует локальный файл. Если загрузка или проверка не прошла, сборка останавливается. При изменении официального пакета сначала проверьте его происхождение и подпись; обновляйте закреплённую сумму согласованно в скрипте, ISS и COMPONENTS.txt.

Для сборки без сети из заранее подготовленных файлов:

```powershell
.\Build-Installer.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe' -FrameworkPath 'C:\Packages\NDP48-x86-x64-AllOS-ENU.exe' -NoDownload
```

Готовый EXE и его `.sha256` появляются в `dist`. Бинарные зависимости в Git не добавляются. Код сборки по MIT; условия Microsoft и OpenCorpora указаны отдельно в `COMPONENTS.txt` и `THIRD-PARTY.txt`.

Сам установщик пока не подписан сертификатом издателя. Windows может показывать предупреждение о неизвестном издателе; подпись вложенного пакета Microsoft проверена и сохранена. Кодовая подпись приложения — отдельный этап перед массовым распространением.

## Проверка сценариев

`tests/Test-Installer.ps1` компилирует отдельный тестовый EXE из того же ISS с заменой внешнего мастера Microsoft тестовым процессом. Он использует только выделенную рабочую папку, не меняет системный Framework, не создаёт системные ярлыки и не регистрирует удаление в Windows. Производственная сборка не содержит тестовых параметров. Проверяется пропуск установленного Framework, порог версии, отказ, успешное завершение, отмена, ошибка и перезагрузка, а также копирование файлов, ярлыки, повторная установка и удаление. Это проверка логики установщика, а не замена испытания реального Microsoft .NET на чистой Windows.

```powershell
.\installer\tests\Test-Installer.ps1 -CompilerPath 'C:\Tools\Inno Setup 6\ISCC.exe' -TestRoot 'C:\Tests\ThirdPerson'
```
