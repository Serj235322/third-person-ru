# Изолированные проверки установщика

Запустите `Test-Installer.ps1` с путями к ISCC.exe и отдельной рабочей папке; команды приведены в [инструкции](../README.md). Приложение должно быть собрано; на проверяющем компьютере нужен .NET Framework 4.8+.

`FrameworkStub.cs` имитирует внешний мастер только в сборке с определением `InstallerTest`. Тестовые ярлыки и установленные файлы размещаются в новой поддиректории рабочей папки. Реестр установки и системный Framework не изменяются. Отчёты и файлы пользовательского тестового документа остаются для анализа; рекурсивной очистки пользовательских путей нет.

Результаты: [VALIDATION.txt](../VALIDATION.txt).
